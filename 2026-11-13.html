Figma 原生 3D 变换，设计稿可继续交给代码

新效果允许沿三轴旋转并调节透视，和 Motion 动效、Dev Mode CSS 及 Figma MCP 串联。重点不是立体效果本身，而是设计师能否把空间关系、运动意图和可实现参数一起交接。

今日总览

今天最明显的变化在创作工具：Figma 把 3D 变换接到动效与交接，Framer 让 Agent 直接生成图像和 Shader，Sketch 的组件变体进入测试版。AI 侧，Gemini 4 Hydrogen 扩大到搜索与开发工具，OpenAI 则公开持续运行 Agent 的隔离实践。单机玩家可以留意《德军总部3》正式确认制作与《雷顿教授与蒸汽新世界》开放预购。国产新能源车方面，腾势 N8 已公布价格，而蔚来补能合作仍要等具体场站落地。

先看这 5 条
  1. Figma 上线原生 3D 变换，并提供 Dev Mode CSS 与 MCP 交接路径。
  2. Framer Agent 可生成与编辑图像、Shader，网页视觉制作更贴近画布内迭代。
  3. Gemini 4 Hydrogen 扩大到搜索、AI Studio 和 Gemini 应用，快速执行型模型成为默认入口。
  4. 《德军总部3》正式确认制作，但尚无发售日与平台清单。
  5. 腾势 N8 以 26.99 万元起上市，大屏座舱值得实车观察而非只看发布参数。

给 UI 设计师的一句话

今天值得带走的判断是：生成能力进入画布后，交接质量比效果炫目更重要。 3D、Shader 和 Agent 输出都要能编辑、能撤销、能说明适用范围；车机和搜索中的 AI 更要让用户看得见依据与边界。
